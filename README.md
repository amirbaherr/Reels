# Reels

## Liquid Glass Motion — «پرامپت‌های آماده موشن‌گرافیک برای Claude»

ریلز عمودی ۱۰۸۰×۱۹۲۰، ۶۰ فریم، ۲۷٫۵ ثانیه، با تم Liquid Glass آیفون (iOS 26) و هماهنگ کلمه‌به‌کلمه با ویس.

- خروجی نهایی: `output/liquid-glass-motion.mp4`
- کامپوزیشن (HTML/CSS/JS): `motion/index.html` — با `?t=12.4` هر لحظه را در مرورگر Chrome ببینید
- رندر فریم‌ها با Playwright: `motion/render.js`
- طراحی صدا (افکت‌ها + موزیک بک‌گراند سنتز شده، بدون فایل کپی‌رایتی): `motion/sfx.py`
- ساخت کامل: `motion/build.sh`

### جزئیات
- شیشه‌ی مایع واقعی: هر پنل یک نقشه‌ی جابه‌جایی (displacement map) اختصاصی دارد که لبه‌ها را مثل لنز می‌شکند + blur/saturate پس‌زمینه، هایلایت لبه‌ی چرخان و سایه‌ی داخلی
- Dynamic Island که در لحظه‌های کلیدی باز می‌شود («در حال جستجو…»، «کپی شد»، «کامنت جدید: موشن»)
- زیرنویس کلمه‌به‌کلمه با زمان‌بندی استخراج‌شده از ویس (Whisper) و هایلایت کلمات کلیدی
- فونت: Pinar FD Medium
